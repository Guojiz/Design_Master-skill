# Design Resource Guide

[English](DESIGN_RESOURCES.md) | [简体中文](DESIGN_RESOURCES.zh-CN.md)

This guide works in two ways: Design Master uses it to select relevant sources automatically, and people can use it directly as a categorized design bookmark collection.

| Resource | Best for |
|---|---|
| [Awwwards](https://www.awwwards.com/) | Creative interaction, web animation, and award-winning sites |
| [Recent Design](https://recent.design/) | Recent experimental websites, technology, and motion |
| [Godly](https://godly.website/) | Alias of Recent Design; kept for old bookmarks |
| [SiteInspire](https://www.siteinspire.com/) | Minimal brand websites, grids, and typography |

## Usage rule

Use a few relevant sources rather than searching everything. Save links and original analysis, not copyrighted images, videos, copy, or page source. Follow discovery-board items back to their original creators whenever possible.
