# 设计资源导览

[English](DESIGN_RESOURCES.md) | [简体中文](DESIGN_RESOURCES.zh-CN.md)

这份导览有两种用途：Design Master 会根据项目自动选择合适的来源，使用者也可以把它直接当作分类清晰的设计网站收藏夹。

## 创意网站与动效

| 资源 | 主要用途 |
|---|---|
| [Awwwards](https://www.awwwards.com/) | 创意交互、网页动画和获奖网站 |
| [Recent Design](https://recent.design/) | 新近实验性网站、科技视觉和动效 |
| [Godly](https://godly.website/) | Recent Design 的旧名称，保留用于兼容原收藏链接 |
| [SiteInspire](https://www.siteinspire.com/) | 极简品牌网站、网格和字体排版 |

## 使用规则

根据项目选择少量高相关来源，不要把所有网站全部搜索一遍。只保存链接与原创分析，不批量保存受版权保护的图片、视频、文案或页面源码。通过灵感聚合网站发现作品后，应尽量追溯并标注原作者。
